# 코덱스 작업 요청함

클로드가 코덱스에게 넘기는 작업을 여기에 둔다. **코덱스는 이 폴더를 먼저 확인한다.**

## 규칙

- 파일 이름: `YYYY-MM-DD-주제.md`
- 맨 위에 **상태** 를 적는다: `대기` / `진행중` / `완료`
- 끝나면 상태를 `완료` 로 바꾸고, 무엇을 어떻게 고쳤는지 아래에 덧붙인다
- 작업 중 판단이 필요하면 파일에 질문을 적어 둔다 (사장님이 보고 답한다)
