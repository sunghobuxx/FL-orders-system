## 반영 내용

1. 대시보드의 고정 ‘상차시작’을 실제 order_batches.status 표시로 교체하고 업체 행을 주문 상세에 연결했다. 주문내역과 동일하게 ordered는 배송중, dispatched는 배송완료로 표시한다.
2. 대시보드와 주문내역은 화면 복귀·앱 활성화 시 조회하고 화면 사용 중 5초 간격으로 갱신한다. 이전 날짜·조회 범위 응답과 화면 이탈 후 응답은 버린다. 갱신 실패도 화면에 표시한다.
3. 주문내역과 명세서에 달력, 이전/다음 날짜, 오늘 버튼을 추가했다. 달력은 월·연도 이동을 지원한다. 기존 API의 date 인자로 30일보다 오래된 날짜도 조회한다.
4. 선택한 날짜의 명세서를 기존 expo-print 기능으로 인쇄한다. 화면에서도 전체 품목을 표시한다. 기존 API가 미수금을 현재 잔액으로 반환하므로 과거 명세서에서는 ‘조회 시점 미수금’으로 표기하고 과거 전일미수금인 것처럼 표시하지 않는다.
5. 대시보드에 전체발주보기/담당 업체만 보기 전환을 추가했다. scope=all일 때 오늘·내일 전체 업체를 표시한다. 각 행에 배송일과 manager_restaurants → users.name 담당자 목록을 표시한다. 담당자 없는 업체는 미지정이다.
6. 배송 인증 사용자는 다른 담당자의 주문 상세를 읽을 수 있다. API가 canManage를 반환하고 앱은 담당 외 주문의 수정·삭제·확인·배송완료 조작을 제한한다. PATCH/DELETE 및 기존 처리 API의 requireBatchAccess 권한 검사는 유지했다. 식당 owner 계정은 기존 인증 검사로 차단된다.
