# 앱 품목 분류를 새 체계(대분류 9개 + 소분류)에 맞추기

**상태: 완료 — 앱 코드 반영·자동 검사 완료, 실기기 확인/새 빌드 미실시** · 작성 2026-09-17 · 웹은 코드 반영 완료(미배포), **DB 전환은 9/18 낮 예정**

## 한 줄

품목 분류를 **대분류 9개 + 소분류 2단**으로 바꾼다. 앱은 분류 이름표를 자체 코드에 들고 있어서
**그대로 두면 새 분류가 `supply`, `frozen` 처럼 영문 코드로 표시된다.**

## 새 분류 (사장님 확정)

| 코드 | 이름 | 비고 |
|---|---|---|
| vegetable | 야채 | |
| fruit | 과일 | |
| **livestock** | **축산** | 기존 `meat` + `dairy` 를 합침 (난류·육가공·정육·유제품) |
| seafood | 수산 | |
| grain | 곡류·면류 | |
| seasoning | 양념·조미 | |
| **frozen** | **냉동** | 신규 |
| **misc** | **기타식품** | 기존 `etc` 를 대체 |
| **supply** | **소모품** | 신규 (장갑·냅킨·종이컵 등 18개) |

**대분류는 이 9개로 고정**하고, 늘어나는 품목은 소분류로 받는다.
기타식품에 비슷한 게 3개 이상 모이면 소분류를 새로 판다.

## 웹은 이렇게 했다 (참고)

`apps/web/lib/products/categories.ts` 한 곳에 모았다 —
`PRODUCT_CATEGORIES` / `CATEGORY_ORDER` / `CATEGORY_LABELS` / `CATEGORY_EMOJI` /
`normalizeCategory()` / `SUBCATEGORIES`.

**`normalizeCategory()` 가 핵심이다.** 옛 값(`meat`·`dairy`·`etc`)과 모르는 값을 새 대분류로
읽어 준다. 그래서 DB 를 바꾸기 전에도, 바꾼 뒤에도 화면이 깨지지 않는다.
회원 발주 화면은 **목록에 없는 분류의 품목을 걸러내 버리기 때문에** 이 안전망이 없으면
소모품 18개가 화면에서 통째로 사라진다.

## 앱에서 할 일

`apps/mobile/app/(tabs)/order.tsx` (다른 화면에도 같은 상수가 있으면 같이)

1. **`CATEGORY_LABELS` / `CATEGORY_EMOJI` / `CATEGORY_ORDER` 를 새 9개로 교체**
   ```ts
   const CATEGORY_ORDER = ['vegetable','fruit','livestock','seafood','grain','seasoning','frozen','misc','supply']
   const CATEGORY_LABELS = { vegetable:'야채', fruit:'과일', livestock:'축산', seafood:'수산',
     grain:'곡류·면류', seasoning:'양념·조미', frozen:'냉동', misc:'기타식품', supply:'소모품' }
   const CATEGORY_EMOJI = { vegetable:'🥬', fruit:'🍎', livestock:'🥚', seafood:'🐟',
     grain:'🍜', seasoning:'🧂', frozen:'❄️', misc:'🧺', supply:'🧻' }
   ```
2. **옛 값을 읽는 매핑을 넣는다** — 앱은 스토어 업데이트가 늦게 퍼져서, 옛 DB 값과 새 값이
   한동안 섞인다. 웹 `normalizeCategory()` 와 같은 규칙:
   `meat → livestock`, `dairy → livestock`, `etc → misc`, 모르는 값 → `misc`
   분류 탭을 만들 때와 품목을 거를 때 **둘 다** 이 함수를 거치게 한다
3. 지금 앱은 모르는 분류를 `extra` 로 뒤에 붙여 영문 코드로 보여준다. 매핑을 넣으면 없어진다
4. 소분류는 이번에 화면에 쓰지 않는다. `/api/member/products` 가 `subcategory` 를 내려주면
   나중에 묶음 표시에 쓸 수 있다

## 검증

1. 앱에서 발주 화면 → 분류 탭이 **한글 9개**로 나오는지
2. 소모품(장갑·냅킨)·냉동 품목이 탭에 보이고 발주되는지
3. DB 전환 **전에도** 탭이 깨지지 않는지 (옛 값 매핑 확인)
