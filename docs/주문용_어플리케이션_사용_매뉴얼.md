# FruitLife 주문용 어플리케이션 사용 매뉴얼

본 매뉴얼은 거래처/식당 담당자가 FruitLife 주문용 모바일 앱을 사용하는 방법을 안내합니다.

## 1. 앱 시작하기

### 1.1 로그인

1. 앱을 실행합니다.
2. 로그인 화면에서 이메일과 비밀번호를 입력합니다.
3. `로그인` 버튼을 누릅니다.

로그인에 실패하면 이메일 또는 비밀번호를 다시 확인해주세요.

### 1.2 알림 권한 허용

앱 최초 로그인 시 푸시 알림 권한 요청이 표시될 수 있습니다.

- 발주 상태 변경
- 공지사항
- 운영 안내

위 내용을 받기 위해 알림 권한을 허용하는 것을 권장합니다.

## 2. 하단 메뉴 안내

앱 하단에는 주요 메뉴가 있습니다.

| 메뉴 | 기능 |
| --- | --- |
| 홈 | 오늘 발주 현황, 미수금, 단가, 주간 발주 요약, 공지 확인 |
| 발주 | 오늘 발주 작성, 발주 상태 확인, 발주 내역 확인 |
| 정산 | 당일 명세서, 명세서 내역, 미수금 확인 |
| 웨이팅 | 매장 웨이팅 관리 |
| 공지·문의 | 공지사항 확인, 문의/불편 접수 |

## 3. 홈 화면

홈 화면에서는 주요 정보를 한눈에 확인할 수 있습니다.

### 3.1 오늘 발주 현황

오늘 발주가 제출되었는지 확인할 수 있습니다.

- `미제출`: 아직 발주를 제출하지 않은 상태
- `제출 완료`: 오늘 발주가 정상 제출된 상태
- 품목 수: 오늘 발주에 포함된 품목 개수

카드를 누르면 `발주` 화면으로 이동합니다.

### 3.2 현재 미수금

현재 남아있는 미수금을 확인할 수 있습니다.

카드를 누르면 `정산` 화면으로 이동합니다.

### 3.3 현재 납품 단가

등록된 품목의 현재 단가를 확인할 수 있습니다.

단가는 관리자에서 입력한 최신 단가 기준으로 표시됩니다.

### 3.4 이번 주 발주 분석

이번 주 발주 품목과 금액을 확인할 수 있습니다.

분석 정보가 등록된 경우 AI 분석 내용도 함께 표시됩니다.

### 3.5 공지사항

최근 공지사항을 확인할 수 있습니다.

자세한 내용은 `공지·문의` 메뉴에서 확인합니다.

## 4. 발주하기

하단 메뉴에서 `발주`를 누릅니다.

발주 화면에는 다음 탭이 있습니다.

- 발주 작성
- 발주 현황
- 발주 내역

### 4.1 발주 작성

1. `발주` 메뉴로 이동합니다.
2. `발주 작성` 탭을 선택합니다.
3. 필요한 품목의 수량을 입력합니다.
4. 입력이 끝나면 `발주 제출` 버튼을 누릅니다.
5. 확인창이 나오면 내용을 확인하고 제출합니다.

수량이 입력되지 않은 품목은 발주에 포함되지 않습니다.

### 4.2 발주 수정

오늘 발주가 아직 처리 전인 경우, 같은 화면에서 수량을 수정한 뒤 다시 제출할 수 있습니다.

기존 발주 품목은 새로 입력한 내용으로 갱신됩니다.

### 4.3 발주 상태 확인

`발주 현황` 탭에서 오늘 발주의 진행 상태를 확인할 수 있습니다.

상태는 다음 순서로 진행됩니다.

| 상태 | 의미 |
| --- | --- |
| 발주접수 | 발주가 접수된 상태 |
| 알림톡발송 | 관리자 확인 후 알림톡 발송 단계 |
| 배송중 | 상품 준비/배송 진행 중 |
| 배송완료 | 배송 완료 |

### 4.4 발주 내역 확인

`발주 내역` 탭에서 최근 발주 내역을 확인할 수 있습니다.

발주 항목을 누르면 해당 날짜의 발주 품목과 수량을 확인할 수 있습니다.

## 5. 정산 확인

하단 메뉴에서 `정산`을 누릅니다.

### 5.1 현재 미수금

현재 남아있는 미수금을 확인할 수 있습니다.

### 5.2 당일 명세서

오늘 납품된 품목과 금액을 확인할 수 있습니다.

명세서에는 다음 정보가 표시됩니다.

- 날짜
- 오늘 납품 금액
- 품목명
- 수량
- 금액

최종 금액은 운영 상황에 따라 지정된 시간 이후 확정될 수 있습니다.

### 5.3 명세서 내역

주차별 또는 날짜별 명세서 내역을 확인할 수 있습니다.

각 내역을 누르면 상세 품목과 금액을 확인할 수 있습니다.

## 6. 웨이팅 관리

하단 메뉴에서 `웨이팅`을 누릅니다.

웨이팅 기능을 사용하는 매장만 이용할 수 있습니다.

### 6.1 웨이팅 목록 확인

웨이팅 고객 목록에서 다음 정보를 확인합니다.

- 고객명
- 인원 수
- 대기 시간
- 현재 상태

### 6.2 고객 호출

대기 중인 고객에게 자리가 나면 `자리남` 버튼을 누릅니다.

고객 상태가 호출됨으로 변경됩니다.

### 6.3 입장 처리

호출된 고객이 입장하면 `입장` 버튼을 누릅니다.

### 6.4 취소/노쇼 처리

고객이 취소하거나 방문하지 않은 경우:

- `취소`
- `노쇼`

버튼을 눌러 상태를 변경합니다.

### 6.5 손님용 웨이팅 URL

웨이팅 화면에서 손님용 URL을 확인할 수 있습니다.

해당 URL을 QR 코드로 만들어 매장 입구에 부착하면 고객이 직접 웨이팅을 등록할 수 있습니다.

## 7. 공지·문의

하단 메뉴에서 `공지·문의`를 누릅니다.

### 7.1 공지사항 확인

`공지게시판` 탭에서 운영 공지사항을 확인합니다.

공지 제목을 누르면 상세 내용을 볼 수 있습니다.

### 7.2 문의/불편 접수

`불편 & 문의` 탭에서 문의를 작성할 수 있습니다.

1. `+ 문의 작성` 버튼을 누릅니다.
2. 제목을 입력합니다.
3. 내용을 입력합니다.
4. 필요 시 사진을 첨부합니다.
5. 등록 버튼을 누릅니다.

### 7.3 문의 내역 확인

작성한 문의는 목록에서 확인할 수 있습니다.

상태는 다음과 같이 표시됩니다.

- 대기중
- 답변완료

답변이 등록되면 상세 화면에서 확인할 수 있습니다.

## 8. 내 정보

홈 화면 오른쪽 상단의 사람 아이콘 또는 내 정보 화면에서 업체 정보를 확인할 수 있습니다.

### 8.1 업체 정보 수정

다음 정보를 확인하거나 수정할 수 있습니다.

- 업체명
- 담당자명
- 연락처
- 휴대폰
- 주소
- 사업자번호
- 계산서 이메일

수정 후 `정보 저장` 버튼을 누릅니다.

### 8.2 비밀번호 변경

1. 새 비밀번호를 입력합니다.
2. 비밀번호 확인란에 한 번 더 입력합니다.
3. `비밀번호 변경` 버튼을 누릅니다.

비밀번호는 8자 이상이어야 합니다.

### 8.3 로그아웃

내 정보 화면 하단의 `로그아웃` 버튼을 누르면 로그아웃됩니다.

## 9. 자주 묻는 질문

### Q. 발주 제출 후 수정할 수 있나요?

오늘 발주 화면에서 다시 수량을 입력하고 제출하면 기존 발주가 갱신됩니다. 단, 관리자 처리 상태에 따라 운영상 수정이 제한될 수 있습니다.

### Q. 발주 품목이 보이지 않습니다.

해당 업체에 등록된 취급 품목이 없을 수 있습니다. 관리자에게 품목 등록을 요청해주세요.

### Q. 명세서 금액이 예상과 다릅니다.

단가 변경, 수량 수정, 배송 확인 상태에 따라 금액이 달라질 수 있습니다. 최종 금액은 관리자 확정 후 확인해주세요.

### Q. 알림이 오지 않습니다.

휴대폰 설정에서 FruitLife 앱의 알림 권한이 켜져 있는지 확인해주세요.

### Q. 로그인이 되지 않습니다.

이메일과 비밀번호를 확인해주세요. 계속 실패하면 관리자에게 계정 상태 확인을 요청해주세요.

## 10. 운영 시 유의사항

- 발주는 매일 필요한 품목만 수량을 입력해 제출합니다.
- 발주 제출 후에는 발주 현황에서 상태를 확인합니다.
- 명세서 금액은 관리자 확인 후 확정될 수 있습니다.
- 문의/불편 사항은 앱에서 작성하면 관리자에게 전달됩니다.
- 웨이팅 기능은 사용하는 매장만 활성화됩니다.
